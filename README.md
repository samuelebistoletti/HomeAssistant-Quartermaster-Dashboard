# Quartermaster Dashboard

Dashboard strategy and cards for the [Quartermaster](https://github.com/samuelebistoletti/HomeAssistant-Quartermaster) integration: inventory by zone, essentials, shopping list with suggestions, proposals to confirm and photo upload. Built for phones first, and works on tablets and desktop, in light and dark themes.

> [!WARNING]
> Under development and not usable yet. There is no release; the first one will be 1.0.0.

## Requirements

- Home Assistant 2026.11.0 or later.
- The [Quartermaster](https://github.com/samuelebistoletti/HomeAssistant-Quartermaster) integration with dashboard API version 1. Without it, or with an integration that is not set up or too old, the dashboard shows a message saying what to do.

## Installation

Once 1.0.0 is released: install **Quartermaster Dashboard** from the Marketplace (**Settings** → **Marketplace**), which adds it as a dashboard resource. Then go to **Settings** → **Dashboards** → **Add dashboard** and pick **Quartermaster** under the community dashboards.

If your dashboards are in YAML mode, the Marketplace cannot add the resource automatically: add `/local/community/HomeAssistant-Quartermaster-Dashboard/quartermaster-dashboard.js` as a resource of type `module` yourself.

## Views

The dashboard is generated by a dashboard strategy from the integration's live data, in the language of each user (English and Italian, English for other languages). It uses sections views: one column on a phone, more columns on a tablet or desktop.

| View | Content |
| --- | --- |
| Overview | Tiles for to buy, suggested, expiring and proposals to confirm (a tap opens the matching view), and the **Go shopping** button. |
| Shopping list | The integration's to-do list (native card) and the **Suggestions** card: each suggestion with its reason ("you have 1, you usually keep 4") and a one-tap add. |
| Essentials | Present, minimum, target and status of each essential; edit minimum and target, add and remove essentials. |
| Zones | One section per zone: last update, the products in it, and the photo upload card for that zone. |
| Proposals | Changes recognized from photos with quantity before and after: confirm all or some, correct product and quantity, reject. |
| Inventory | Products by zone with plus and minus, set quantity, new product. |
| Expiry | Native calendar of best-before dates. |
| History | Latest movements with their channel; undo an operation. |

Users who may not write (non-administrators, unless the integration's `non_admin_writes` option is on) see the same data without the write controls.

The views are rebuilt when the dashboard loads and when Home Assistant's entity registry changes; the cards update live. After adding a zone, reload the dashboard to get its section.

## Cards

The cards can also be added to any dashboard from the card picker (search "Quartermaster"). Each has a visual editor.

| Card | Type | Options |
| --- | --- | --- |
| Suggestions | `custom:quartermaster-suggestions-card` | `title` |
| Essentials | `custom:quartermaster-essentials-card` | `title` |
| Proposals | `custom:quartermaster-proposals-card` | `title` |
| Inventory | `custom:quartermaster-inventory-card` | `title`, `zone` (zone id; all zones when omitted) |
| History | `custom:quartermaster-history-card` | `title`, `limit` (1–500, default 50) |
| Zone | `custom:quartermaster-zone-card` | `zone` (required), `title` |
| Photo upload | `custom:quartermaster-photo-card` | `title`, `zone` (preselected zone) |

### Photo upload

The card offers the camera where the browser or app allows it, and the gallery otherwise. Before sending, the photo is turned upright, resized to 1280 px on the long side and re-encoded as JPEG (quality 80) in the browser, which also removes its metadata (location included). Photos still over 2 MB are refused. The result (changes recorded or to confirm in **Proposals**) shows under the button.

> [!NOTE]
> In the Home Assistant Android app the file field opens only the gallery, not the camera ([home-assistant/android#6055](https://github.com/home-assistant/android/issues/6055)). Take the photo with the camera app first, or send it to the Quartermaster Telegram bot, which is the quickest way from a phone.

## Development

```bash
npm ci
npm run lint     # ESLint + TypeScript
npm test         # Web Test Runner (Chrome)
npm run build    # Rollup -> dist/quartermaster-dashboard.js (commit it)
```

The integration repository's dev Home Assistant loads `dist/` from this repository when both are cloned side by side. See its `CONTRIBUTING.md`.
